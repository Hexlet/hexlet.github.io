# Как задеплоить проект на Railway

> Бесплатный деплой Node.js-приложения из репозитория GitHub без банковской карты.

Railway собирает приложение прямо из репозитория на GitHub и выдаёт ему публичный адрес. Бесплатного тарифа хватает, чтобы показать проект наставнику, и карта для него не нужна. Инструкция проверена 11 ноября 2026 года на учебном приложении [react-todo-app-with-backend](https://github.com/hexlet-components/react-todo-app-with-backend), в котором фронтенд на React раздаёт сервер на Fastify.

Если в задании проекта назван другой сервис и он у вас работает, деплойте туда. Railway пригодится, когда тот сервис недоступен или просит карту.

## Что понадобится

Нужен аккаунт на [GitHub](https://github.com/) и репозиторий с приложением. Аккаунт на Railway создаётся входом через GitHub, отдельная регистрация не нужна.

## Подготовьте приложение

Railway запускает приложение в контейнере и сам выбирает порт. Поэтому сервер должен слушать порт из переменной окружения `PORT` и адрес `0.0.0.0` ([требование Railway](https://docs.railway.com/reference/errors/application-failed-to-respond)). Fastify по умолчанию слушает только `127.0.0.1`, и снаружи такое приложение недоступно, даже когда в логах всё в порядке.

```javascript
const port = process.env.PORT || 5000;

app.listen({ port, host: '0.0.0.0' });
```

Если у проекта есть фронтенд, его собирает скрипт `build` в `package.json`, а готовые файлы раздаёт сервер. Railway выполняет `build` перед запуском сам, поэтому собранную папку (`dist` у Vite) в репозиторий класть не нужно. Сервер запускается скриптом `start`.

```json
{
  "scripts": {
    "build": "vite build",
    "start": "node bin/server.js"
  }
}
```

Раздачу фронтенда сервером показывает [исходная статья в блоге Хекслета](https://ru.hexlet.io/blog/posts/railway). Там использован устаревший create-react-app, у Vite папка сборки называется `dist` вместо `build`, остальное работает так же.

Проверьте локально, что после `npm run build` и `npm start` приложение открывается в браузере. Если так не работает на вашем компьютере, на Railway тоже не заработает.

## Войдите и проверьте тариф

Откройте [railway.com](https://railway.com/) и нажмите **Continue with GitHub**. Новый аккаунт получает пробный период, его хватает для деплоя.

Если вы уже регистрировались на Railway раньше, пробный период мог закончиться. Тогда Railway не даст создать проект и напишет «Your trial has expired». Откройте **Settings → Plans** и нажмите **Downgrade to Free** внизу страницы. Тариф Free включается без карты.

![Страница тарифов Railway после перехода на Free, 1 доллар кредитов в месяц, до 1 vCPU и 0,5 ГБ памяти на сервис, 0,5 ГБ хранилища](/img/docs/img-220--railway-free-plan.png)

## Создайте проект

На главной странице Railway нажмите **New** и выберите **GitHub Repository**.

![Меню нового проекта в Railway, первый пункт GitHub Repository](/img/docs/img-221--railway-new-project.png)

Начните вводить имя репозитория и выберите его в списке.

![Поиск репозитория в Railway, по запросу react-todo найдены два репозитория](/img/docs/img-222--railway-select-repo.png)

Если нужного репозитория в списке нет, у Railway нет к нему доступа. Очистите строку поиска, выберите **Configure GitHub App** и на странице GitHub дайте доступ к этому репозиторию. Достаточно отметить **Only select repositories** и выбрать один репозиторий.

После выбора репозитория Railway создаёт сервис и запускает сборку. Если в корне репозитория лежит `Dockerfile`, Railway собирает образ по нему. Если нет, сам определяет Node.js, устанавливает зависимости, выполняет `build` и запускает `start`. Версию Node.js он берёт из поля `engines` в `package.json` или из файла `.nvmrc`.

## Проверьте сборку

Сборка занимает около минуты. Ход сборки показывает вкладка **Deployments**, а **View logs** открывает журналы. Во вкладке **Build Logs** видна установка зависимостей и сборка, во вкладке **Deploy Logs** вывод запущенного приложения.

Сборка закончена, когда у деплоя стоит статус **ACTIVE**, а у сервиса **Online**.

![Вкладка Deployments в Railway, деплой со статусом ACTIVE и подписью Deployment successful, сервис Online](/img/docs/img-223--railway-deployment-active.png)

## Получите адрес

Пока у сервиса нет адреса, из интернета он недоступен. Откройте **Settings**, найдите раздел **Networking** и нажмите **Generate Domain**. Railway выдаст адрес вида `<имя-сервиса>-production.up.railway.app`.

![Раздел Networking в настройках сервиса, выданный домен на up.railway.app, порт 8080 и кнопка Generate Domain](/img/docs/img-224--railway-generate-domain.png)

Откройте адрес в браузере. Если приложение работает, этот адрес отправляйте наставнику.

![Учебное приложение Hexlet Todos, открытое по адресу на Railway, с добавленной задачей](/img/docs/img-225--railway-app-online.png)

После каждого пуша в ветку `main` Railway пересобирает и перезапускает приложение сам.

## Ограничения бесплатного тарифа

На тарифе Free сервису выделяется 1 vCPU и 0,5 ГБ памяти, а в месяц начисляется кредитов на 1 доллар. Этого хватает, чтобы показать учебный проект, но держать приложение постоянно не получится. Приложение без запросов засыпает, и первый запрос после паузы открывается дольше обычного.

Число проектов на Free ограничено. Если Railway отвечает «Free plan resource provision limit exceeded», удалите ненужный проект в **Settings → Danger → Delete Project** у самого проекта. Свой домен на этом тарифе подключить нельзя.

## Если что-то пошло не так

Сначала откройте журналы деплоя, причина почти всегда написана там.

- **Сервис падает сразу после старта, в журнале `Killed` и код 137.** Приложению не хватило 0,5 ГБ памяти. Так бывает, например, с базой данных, которая работает внутри процесса приложения, вроде PGlite.
- **Статус Online, а адрес не открывается.** Сервер слушает `127.0.0.1` или фиксированный порт. Проверьте `host: '0.0.0.0'` и `process.env.PORT`.
- **Фронтенд не открывается, а API отвечает.** Не выполнилась сборка фронтенда. Проверьте скрипт `build` в `package.json` и путь, по которому сервер раздаёт собранные файлы.
- **Railway пишет «Free plan resource provision limit exceeded».** Лимит проектов исчерпан. Удалите старый проект или добавьте сервис в существующий.
