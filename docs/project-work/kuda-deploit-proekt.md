# Куда задеплоить учебный проект

> Что подготовить в приложении перед деплоем и как выбрать сервис, если основной не работает.

Во многих проектах Хекслета приложение нужно выложить в интернет, чтобы наставник открыл его по ссылке. Уроки о деплое построены на Render, но у части студентов из России он открывается только через VPN или просит привязать банковскую карту. В этой статье собрано то, что нужно сделать в приложении для любого сервиса, и сравнение сервисов, на которые можно задеплоить проект.

## Подготовьте приложение

Требования ниже общие для всех сервисов из этой статьи. Если приложение им отвечает, перенести его с одного сервиса на другой можно за несколько минут.

**Сервер слушает порт из переменной `PORT` и адрес `0.0.0.0`.** Сервис сам выбирает порт и передаёт его приложению в переменной окружения. Многие фреймворки по умолчанию слушают только `127.0.0.1`, и снаружи такое приложение недоступно, даже когда в журнале всё в порядке.

```javascript
const port = process.env.PORT || 3000;

app.listen({ port, host: '0.0.0.0' });
```

**Настройки и секреты приходят из переменных окружения.** Адрес базы данных, ключи и пароли не записываются в код и не попадают в репозиторий. Приложение читает их из окружения, например из `DATABASE_URL`, а значения задаются в настройках сервиса.

**Сборка и запуск выполняются командами.** Сервис скачивает репозиторий и собирает приложение сам, поэтому собранные файлы, например папка `dist` фронтенда, в репозиторий не кладутся. Команды сборки и запуска обычно лежат в `package.json`, `Makefile` или `Dockerfile`.

**Данные хранятся в базе.** Файлы внутри запущенного приложения пропадают при каждом перезапуске и новом деплое, как и база в памяти, например H2. Записи, которые должны сохраняться, держите в PostgreSQL.

Перед деплоем проверьте локально, что приложение собирается и запускается теми же командами, которые выполнит сервис. Если не работает на вашем компьютере, на сервисе тоже не заработает.

## Выберите сервис

Начните с сервиса, на котором построен урок или проект. Если он не открывается, просит карту или не даёт создать бесплатный сервис, переходите к следующему в таблице. Данные в таблице проверены 11 ноября 2026 года.

| | Render | Railway |
| --- | --- | --- |
| Карта для бесплатного тарифа | Не нужна по условиям Render, но части студентов он её требует | Не нужна |
| Доступ из России | У части студентов только через VPN | Не проверен |
| Бесплатный веб-сервис | 512 МБ памяти, 750 часов в месяц на все сервисы, засыпает через 15 минут без запросов | 0,5 ГБ памяти, кредит 1 доллар в месяц на все сервисы, засыпает без запросов |
| Бесплатная база PostgreSQL | 1 ГБ, удаляется через 30 дней, одна на рабочее пространство | Том 0,5 ГБ, хранится, пока есть кредит |
| Подключение базы | Строку подключения копируют вручную | Сервис подставляет переменные базы сам |
| Java | Только через `Dockerfile` | Собирается автоматически по Gradle или Maven, подходит и `Dockerfile` ([Railpack](https://railpack.com/languages/java)) |
| Инструкция | [Деплой на Render](deploy-na-render.md) | [Деплой на Railway](deploy-na-railway.md) |

Если в чек-листе проекта назван Render, а он у вас не работает, задеплойте проект на другой сервис из таблицы и напишите об этом наставнику при сдаче.

## Если ни один сервис не работает

Напишите наставнику, какие сервисы вы пробовали и что они ответили. Приложите сообщение об ошибке или снимок экрана. Наставник подскажет, как сдать проект.
